# Triage labels

The skills speak in five canonical triage roles (from mattpocock/skills). This maps them to the labels in this tracker.

| Role | Label | Meaning |
|---|---|---|
| needs-triage | `needs-triage` | Joe needs to evaluate this issue |
| needs-info | `needs-info` | Waiting for more information or a judgement |
| ready-for-agent | `ready-for-agent` | Fully specified, ready for an AFK agent |
| ready-for-human | `ready-for-human` | Requires human implementation (learning-critical) |
| wontfix | `wontfix` | Will not be actioned |

Scope label: `future` for parked directions (PRD Section 16).
